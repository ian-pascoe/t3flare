## Checks per step

- **Step 1:** the alchemy plugin bug drafted as an upstream issue with the spike's evidence, for the owner to file; t3's heavy queries (thread window, shell snapshot, search) on a deployed stage with turn items; module-level state after a reset in a warm isolate.
- **Step 0 (done):** bundle size against 64 MiB; startup time; heap after boot against 128 MB; cold-boot cost; the list of streams the client subscribes to at connect, each of which must emit a first value; read latency behind open transactions; the bootstrap grant's scope for a first pairing.
- **Step 2a, part 1 (done):** pi-durable version rule: run cloudpid's `effect-durable` tests against upstream unpatched; use upstream if they pass, otherwise pin exactly what cloudpid runs. How entangled cloudpid's extension slices are.
- **Step 2a, part 2:** the proxy's 429 shape: a live Commissary's "all credentials cooling down" (`model_cooldown`) and spend-limit (`spend_limit_reached`) answers on `/v1/messages`, streaming and not, give the status, `retry-after` and body the classifier's fixtures assume; its refused-key answer (401, `{"error":"Invalid API key"}`) likewise; how many requests one limited turn makes (pi-durable's retries); how computerd starts a command (its process group and session) before choosing the kill.
- **Step 4a:** each CLI reaches the proxy through its own base-URL setting and calls no vendor host (Codex `model_providers` with `wire_api = "responses"` against Commissary's Responses API; pi's `models.json`); the key's way in, settled for ADR-0016 with evidence, and if it is an intercept: a streaming model call (30 min or more, with idle gaps) through the handler, each CLI trusting the ephemeral CA, intercepts registered before every Container start; t3's Pi adapter in the cloud: its extension file (`--extension`, written to t3's cache directory) reaches the Container, and its process-group stop (`detached`, `signalProcessGroup`) maps onto the process channel; `bwrap` user namespaces in the image (otherwise Codex runs `danger-full-access`); what happens to an exec'd process when its Workspace DO resets.
- **Step 4b:** Claude Code starts on the proxy with no login prompt (`ANTHROPIC_BASE_URL` and the key path 4a chose); OpenCode's provider config on the proxy.
