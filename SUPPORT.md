# Support

t3flare is supported on a best-effort basis by one Maintainer. Only the tip of `main` is supported; there are no
releases.

- **Questions** about deploying or using t3flare: [Discussions, Q&A](https://github.com/spiritledsoftware/t3flare/discussions/categories/q-a).
- **Ideas**: [Discussions, Ideas](https://github.com/spiritledsoftware/t3flare/discussions/categories/ideas).
- **Bugs and concrete feature requests**: [Issues](https://github.com/spiritledsoftware/t3flare/issues/new/choose).
- **Vulnerabilities**: private reporting, as [`SECURITY.md`](SECURITY.md) describes.
- **The stock T3 Code clients and unmodified t3code**: [pingdotgg/t3code](https://github.com/pingdotgg/t3code).

To contribute, see [`CONTRIBUTING.md`](CONTRIBUTING.md).
