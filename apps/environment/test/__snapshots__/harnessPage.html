Extensions

What Pi Durable's harness offers the model. A switch saves at once; a setting saves with its Save button.

Code mode

codemode

The codemode tool: the model writes a JavaScript script whose tool calls run as nested calls, each judged exactly as a direct call (ADR-0027). Scripts run in the codemode sandbox Worker.

Estimated tokens the tool declarations in the code mode section may use; past it, scripts find tools with searchTools().

Tool search

tool-search

The tool_search tool, which loads a deferred tool for direct use. Off: every tool is offered directly.

Offered tools

offered-tools

Which tools the model is offered without a search: core (coding tools, ask_user, code mode, tool search, t3's tools), code mode only, or everything. Tools not offered stay callable from scripts and by tool search.

Always on

core: about 14.5k tokens of declarations per request; codemode-only: about 3k; everything: every tool direct.
